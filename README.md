# 👗 ECOSTYLE – Customized Outfit Creator & Sharing Platform

ECOSTYLE is a full-stack e-commerce web application where users can design custom outfits, share them with the community, and earn points based on interactions. The platform encourages creativity and community engagement while gamifying fashion design.

## Features

###  User Authentication
1. Sign up & login system with secure password storage
2. Session/token-based authentication

###  Outfit Customization
1. Interactive outfit creator
2. Drag-and-drop or selection-based customization (future scope: canvas/image layering)

### Community & Sharing
1. Share your outfit with the community
2. Like, comment, and explore other users’ designs

###  Points & Rewards System
1. Earn points for:
2. Creating outfits
3. Receiving likes/shares
4. Referrals (future scope)
5. Points leaderboard for top creators

###  Profile Management
1. View your designs and point history
2. Edit basic profile information
